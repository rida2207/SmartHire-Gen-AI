How to Become a Data Analyst
A data analyst collects, cleans, and interprets data to help a business make decisions. 
It is one of the most common first roles for people moving into data.

Core skills
SQL — the single most important skill. You must be able to write SELECT queries with JOINs, GROUP BY, and filtering.
Spreadsheets — Excel or Google Sheets: pivot tables, lookups, charts.
A visualisation tool — Power BI or Tableau to build dashboards.
Statistics basics — averages, distributions, correlation, and how to spot a misleading chart.
Python (optional but valued) — pandas for cleaning and matplotlib for plots.
Switching from another role
If you are coming from a non-data job, the fastest path is:

Learn SQL first and practise on real datasets.
Rebuild reports you already make by hand into a dashboard.
Do two or three portfolio projects analysing public datasets.
Apply to "junior data analyst" or "business analyst" roles.
What a data analyst does NOT need at the start
You do not need machine learning, deep learning, or a statistics degree to get a first data-analyst job. Those matter more for data-scientist roles later.

Typical entry-level expectations:
Comfortable writing SQL queries without help.
Can build a clean dashboard and explain what it shows.
Can take a vague business question and turn it into a data question.

Projects required or recommended:
* *SQL-Driven Revenue Analysis Project:* Focuses on multi-table joins, CTEs, window functions, and transactional database querying to answer core business and operational questions.
* *Interactive Dashboard / BI Project:* Built using tools like Power BI, Tableau, or Excel to display executive-ready metrics, key performance indicators (KPIs), and visual data stories.
* *Exploratory Data Analysis (EDA) & Cleaning Project:* Utilizes Python (Pandas and NumPy) to handle missing values, duplicates, and statistical correlations on messy, real-world datasets (such as from Kaggle).
* *End-to-End Portfolio Project:* Combines a full workflow—from problem definition and data processing to insight generation—backed by a clean GitHub README and clear business impact statements.
